# taiwan-market-lab
AI-powered Taiwan stock analysis and prediction platform

## Project Overview

A platform that combines Taiwan stock market data,
analyst opinions, global economic events, and AI-powered
research to help users understand market trends.

Users can also submit stock price predictions and
track their historical prediction accuracy.

## Core Features

1. Taiwan Stock Explorer
2. Analyst Intelligence
3. Global Market Intelligence
4. AI Stock Research Reports
5. User Stock Predictions
6. Prediction Accuracy Dashboard
7. Market Sentiment and Leaderboard

## Tech Stack

- Frontend: Next.js + React
- Styling: Tailwind CSS
- Database: Supabase / PostgreSQL
- Charts: Recharts
- AI: LLM API
- Stock Data: TWSE / FinMind
